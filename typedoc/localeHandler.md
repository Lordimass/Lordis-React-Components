# localeHandler

## Variables

| Variable | Description |
| ------ | ------ |
| [LocaleContext](localeHandler/LocaleContext.md) | Context wrapper which provides the user's locale, associated currency, and country. It's value should be set to the return value of [useLocale](localeHandler/useLocale.md) to automatically fetch these details by reverse geocoding the IP address. |

## Functions

| Function | Description |
| ------ | ------ |
| [useLocale](localeHandler/useLocale.md) | Automatically fetch the user's locale, associated currency, and country. This is done based on the user |
