# ga/events

## Functions

| Function | Description |
| ------ | ------ |
| [trackAddPaymentInfo](events/trackAddPaymentInfo.md) | This event signifies a user has submitted their payment information in an ecommerce checkout process. |
| [trackAddShippingInfo](events/trackAddShippingInfo.md) | This event signifies a user has submitted their shipping information in an ecommerce checkout process. |
| [trackAddToCart](events/trackAddToCart.md) | This event signifies that an item was added to a cart for purchase. |
| [trackAddToWishlist](events/trackAddToWishlist.md) | The event signifies that an item was added to a wishlist. Use this event to identify popular gift items in your app. |
| [trackBeginCheckout](events/trackBeginCheckout.md) | This event signifies that a user has begun a checkout. |
| [trackEarnVirtualCurrency](events/trackEarnVirtualCurrency.md) | This event measures when a user is awarded virtual currency in a game. Log this along with [trackSpendVirtualCurrency](events/trackSpendVirtualCurrency.md) to better understand your virtual economy. |
| [trackJoinGroup](events/trackJoinGroup.md) | Log this event when a user joins a group such as a guild, team, or family. Use this event to analyze how popular certain groups or social features are. |
| [trackLogin](events/trackLogin.md) | Send this event to signify that a user has logged in to your website or app. |
| [trackPageView](events/trackPageView.md) | Records a user viewing a page. |
| [trackPurchase](events/trackPurchase.md) | This event signifies when one or more items is purchased by a user. |
| [trackRefund](events/trackRefund.md) | This event signifies when one or more items is refunded to a user. |
| [trackRemoveFromCart](events/trackRemoveFromCart.md) | This event signifies that an item was removed from a cart. |
| [trackSearch](events/trackSearch.md) | Log this event to indicate when the user has performed a search. You can use this event to identify what users are searching for on your website or app. For example, you could send this event when a user views a search results page after performing a search. |
| [trackSelectContent](events/trackSelectContent.md) | This event signifies that a user has selected some content of a certain type. This event can help you identify popular content and categories of content on your website or app. |
| [trackSelectItem](events/trackSelectItem.md) | This event signifies an item was selected from a list. |
| [trackSelectPromotion](events/trackSelectPromotion.md) | This event signifies a promotion was selected from a list. |
| [trackShare](events/trackShare.md) | Use this event when a user has shared content. |
| [trackSignUp](events/trackSignUp.md) | This event indicates that a user has signed up for an account. Use this event to understand the different behaviors of logged in and logged-out users. |
| [trackSpendVirtualCurrency](events/trackSpendVirtualCurrency.md) | This event measures the sale of virtual goods in your app and helps you identify which virtual goods are the most popular. |
| [trackTutorialBegin](events/trackTutorialBegin.md) | This event signifies the start of the on-boarding process. Use this in a funnel with [trackTutorialComplete](events/trackTutorialComplete.md) to understand how many users complete the tutorial. |
| [trackTutorialComplete](events/trackTutorialComplete.md) | This event signifies the user's completion of your on-boarding process. Use this in a funnel with [trackTutorialBegin](events/trackTutorialBegin.md) to understand how many users complete the tutorial. |
| [trackViewCart](events/trackViewCart.md) | This event signifies that a user viewed their cart. |
| [trackViewItem](events/trackViewItem.md) | This event signifies that some content was shown to the user. Use this event to discover the most popular items viewed. |
| [trackViewItemList](events/trackViewItemList.md) | - |
| [trackViewPromotion](events/trackViewPromotion.md) | This event signifies a promotion was viewed from a list. |
